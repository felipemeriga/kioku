Themed MUI Tabs — Rubik 600 sentence-case labels with a magenta indicator.

## Use
Switching views inside one page (Briefing · Documents · Memory). `Kioku.Tabs` takes `tabs` (labels) and an initial `value`.

## Notes
- Source: `frontend/src/theme.ts (MuiTab)` (kioku@ba12918), bundled as-is; `window.Kioku.Tabs` comes pre-wrapped in `Kioku.Provider`.
- Previews run on offline demo data (`Kioku.fixtures`); in the app the same component talks to the real API.
