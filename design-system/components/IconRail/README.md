The left rail: the 記 hanko mark with the KIOKU wordmark and キオク furigana, Chat · Documents · Settings, and the signed-in user with sign-out.

## Use
Primary navigation. Clicking the active item toggles the ContextPanel. Consumer supplies `activePage`, `onNavigate`, `onTogglePanel`, `userEmail`, `onSignOut`.

## Notes
- Source: `frontend/src/components/IconRail.tsx` (kioku@ba12918), bundled as-is; `window.Kioku.IconRail` comes pre-wrapped in `Kioku.Provider`.
- Previews run on offline demo data (`Kioku.fixtures`); in the app the same component talks to the real API.
