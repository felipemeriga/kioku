Themed MUI Divider in the `line` color.

## Use
Separate groups inside panels and dialogs. It is a decorative hairline (1.3:1) — don't rely on it to separate controls.

## Notes
- Source: `frontend/src/theme.ts (MuiDivider)` (kioku@ba12918), bundled as-is; `window.Kioku.Divider` comes pre-wrapped in `Kioku.Provider`.
- Previews run on offline demo data (`Kioku.fixtures`); in the app the same component talks to the real API.
