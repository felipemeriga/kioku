# Logos

- `kioku-hanko.svg` — the hanko stamp mark (64×64): `ink` tile, magenta→cyan gradient frame, glowing 記 in `magenta-glow`, `cyan` scan ticks. Copied verbatim from `frontend/public/logo.svg`; it is the favicon and the IconRail mark. Full-color only — it carries its own `ink` ground, so place it on `ink` or `surface`. The 記 is live text set in Noto Sans JP 900; outside a page that loads that font it falls back to the system's Japanese face.
- The wordmark is type, not a file: `KIOKU` in Rubik 700 (`display`) with `キオク` furigana in `jp` above it, `text` on `ink`.
