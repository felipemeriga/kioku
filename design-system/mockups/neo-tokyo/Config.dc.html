03

Mem0 memory

Memory is self-hosted and auto-on for repo folders — no API key, no connection step. Any folder wired as a repo (via kioku init) gets episodic + eternal memory automatically, scoped to that repo.

Agents write memories with the save_memory tool and read them with search_memory. Browse or edit a repo’s memories from its folder’s Memory tab.

04

Connect MCP Client

Add this to your MCP client configuration (e.g., .mcp.json for Claude Code):

{
  "mcpServers": {
    "kioku": {
      "type": "sse",
      "url": "http://localhost:8001/sse",
      "headers": { "Authorization": "Bearer <your-api-key>" }
    }
  }
}
