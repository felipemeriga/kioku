Hybrid search with RRF

Kioku runs BM25 (Postgres tsvector) and vector search (pgvector, HNSW) in parallel, then fuses the two rankings with Reciprocal Rank Fusion.

Why RRF

▸ No score calibration between retrievers ▸ One knob: k (we use 60) 
def rrf(ranks, k=60):
    return sum(1 / (k + r) for r in ranks)
The fused list is then reranked by a cross-encoder before it reaches the model.
