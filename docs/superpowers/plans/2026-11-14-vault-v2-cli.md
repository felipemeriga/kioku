# Vault V2 CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Execute approved V2 usage recipes without copying credentials into repositories or model tools.
**Architecture:** Resolve every selected immutable usage in one server request. Materialize protected per-invocation files, then reuse the existing bounded process-group executor and output redactor; clean files on every ordinary exit.
**Tech Stack:** Node TypeScript, OpenSSH, yaml, smol-toml.
**Spec:** docs/superpowers/specs/2026-11-14-resource-credentials-v2-design.md

## Global Constraints
- Preserve V1 binding resolution, stream redaction, deadlines, cancellation and HTTPS transport.
- Raw secret argv requires explicit CLI acknowledgement and server capability grant.
- SSH always uses pinned host keys and per-invocation files; no resident daemon.
- Never modify original configuration files. Temporary copies use 0700 directories and 0600 files.
- Hard kill can leave artifacts: bounded ownership-checked stale cleanup, no secure erasure claim.

## Review Focus
- Config prototype keys, malformed formats and paths must fail before spawn.
- Multiple deliveries must resolve and materialize before a single command begins.
- Encrypted SSH keys need passphrase helper and noninteractive execution.
- Cleanup must preserve unrelated files and reject symlinks.
- Existing filled-output cancellation must retain its behavior.

## Execution ledger

- Contract: resolve-v2 selects usage UUID/revision plus credential revision; returned delivery identities are checked exactly. Legacy resolve path remains separate.
- Ruling: config patch paths are decoded segment arrays for all formats; existing parent objects required, final safe leaf may be added. Temporary filenames are generated, never user paths.
- Ruling: SSH uses full trusted pinned public key directly in isolated known_hosts, avoiding keyscan/TOFU; private keys and askpass files remain invocation-local.
- Ruling: AWS file preset exclusively default-profile TOML with complete key pair and optional token, trusted temporary AWS_SHARED_CREDENTIALS_FILE override and isolated default chain.
- Local proof: real encrypted key and isolated sshd authentication succeeded; wrong pinned host failed. Linux runners lacking sshd initialization explicitly skip only fixture test; current macOS run skipped none.
- Local native proof: loopback device-only API resolve to protected JSON file to real consumer, exact revisions, redacted stdout passed.
- All changes require parent review before merge/release. Published binary/server E2E remains parent-owned.
